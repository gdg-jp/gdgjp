イベントについて

「開発の工夫を教えて！」

このイベントは、 推しのツール、開発環境、テスト、日々の工夫を、 LTと懇親会を通して気軽に共有するMeetup です。

開発に携わる方はもちろん、これから開発を始めたい方や 他の人の工夫を知りたい方も歓迎です。

LTのあとは懇親会を開催します。 発表をきっかけに、普段使っているツールや開発の悩みを話しながら、 新しいヒントやつながりを見つけましょう。

こんな方におすすめ

  • 他の人の推しツールや開発環境を知りたい
  • テストや開発プロセスの工夫を共有したい
  • LTを聞いたり、気軽に発表したりしてみたい
  • 神戸・関西で開発に関心のある人と交流したい
{ 開発経験や職種は問いません。お気軽にご参加ください！ }

Lightning Talk

推しのツール、開発環境、テスト、日々の工夫などを LT形式で共有します。

懇親会

アンチハラスメントポリシー
