# Working in this harness

Read [DESIGN.md](DESIGN.md) before design work. Use the matching local Skill:

- [Build](.agents/skills/design-build/SKILL.md): create or change a page.
- [Review](.agents/skills/design-review/SKILL.md): inspect an existing artifact.
- [Improve](.agents/skills/design-improve/SKILL.md): propose knowledge for future tasks.

Proposals are observations, not policy. Use the project's existing authorization and review process before accepting them. These example files do not establish a real project's brand policy.
