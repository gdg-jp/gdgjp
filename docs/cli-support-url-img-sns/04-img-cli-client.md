# Stage 04 — img Go CLI client

## Context

Stage 03 added CLI-scoped JSON routes under `img/app/routes/api.cli.v1.*.ts`, bundled
into `img/openapi/`. This stage adds the Go CLI package that talks to them, following the same
shape as the existing `cli/internal/connpass/` + `cli/internal/command/connpass.go` pair — the
established template for every app in this plan, per `00-overview.md`.

Depends on Stage 03 (needs the bundled `img/openapi/openapi.yaml` to generate a client against)
and Stage 02 (`cliutil.WithToken`/`cliutil.PrintJSON` — use them from the start, do not write a
local `withImgToken`/`printImgJSON` duplicate).

Read first: `cli/internal/connpass/client.go` (the exact pattern: `NewClient()`/`NewClientAt`,
`bearer(token)` `RequestEditorFn`, `decodeResponse[T]`, type aliases to generated OpenAPI models),
`cli/internal/connpass/generate.go` (the `//go:generate` directive shape), `cli/internal/command/connpass.go`
(Cobra command tree, flag conventions), `cli/internal/command/root.go` (registration point).

## Design

### 1. `cli/internal/img/`

- `generate.go`: `//go:generate sh -c "pnpm --dir ../../.. --filter @gdgjp/img openapi:bundle &&
  go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen --config oapi-codegen.yaml
  ../../../img/openapi/dist/openapi.yaml"` (mirrors `cli/internal/connpass/generate.go:3` verbatim,
  substituting `img` for `connpass`).
- `oapi-codegen.yaml`: same shape as `cli/internal/connpass/oapi-codegen.yaml` (models + client
  generation, package `openapigen`).
- `openapigen/openapi.gen.go`: generated, committed (run `go generate ./...` from `cli/`, don't
  hand-write it).
- `client.go`: `defaultBaseURL = "https://img.gdgs.jp"`, overridable via `GDG_IMG_URL` env var
  (mirroring `GDG_CONNPASS_URL`). `img.HTTPError` with a `HTTPStatus() int` method (Stage 02's
  `cliutil.StatusError` interface). Methods: `Upload(ctx, token, filePath string, chapterID *int)
  (UploadResult, error)`, `List(ctx, token, options) (ListImagesResponse, error)`,
  `Get(ctx, token, id string)
  (GetImageResponse, error)`, `Replace(ctx, token, id, filePath string) (ReplaceResult, error)`,
  `UploadMobile(ctx, token, id, filePath string) (MobileResult, error)`,
  `Delete(ctx, token, id string) (DeleteResult, error)` — each a thin wrapper multipart-encoding
  the file (mirror `connpass/client.go`'s `UploadEventImage`'s multipart-construction code,
  `client.go:193-234`) and decoding via `decodeResponse[T]`.

### 2. `cli/internal/command/img.go`

```go
func newImgCommand(credentials store.CredentialStore) *cobra.Command
```

Registered in `root.go` via `root.AddCommand(newImgCommand(credentials))`, alongside the existing
`newConnpassCommand`/`newWikiCommand`/`newAccountsCommand`/`newAgentCommand` calls.

Every subcommand's `RunE` calls `cliutil.WithToken(cmd.Context(), credentials, func(token string)
(T, error) { ... })` then `cliutil.PrintJSON(cmd.OutOrStdout(), result)` — no package-local retry
or print helper.

### API Contract

| Command | Args / flags | stdout (on success) |
|---|---|---|
| `gdg img list [--chapter-id ID] [--limit N] [--cursor C]` | bounded discovery | `{ "images": [...], "nextCursor": ... }` |
| `gdg img get IMAGE_ID` | existing-image discovery | `{ "image": {...} }` |
| `gdg img upload FILE [--chapter-id ID]` | `--chapter-id` required for multi-chapter callers; server is authoritative | `{ "id": "...", "url": "..." }` |
| `gdg img replace IMAGE_ID FILE` | two positionals | `{ "id": "...", "url": "...", "updatedAt": 0 }` |
| `gdg img mobile IMAGE_ID FILE` | two positionals | `{ "id": "...", "updatedAt": 0 }` |
| `gdg img delete IMAGE_ID` | one positional | `{ "id": "...", "deleted": true }` |

No `--alt`/alt-text flag on any subcommand — the `images` table has no alt-text column (unlike
sns's `post_media`); do not add one. On failure, every subcommand returns a non-zero exit code and
writes the server's `{ error: string }` body's `error` field as a one-line message to stderr
(matching the existing `HTTPError.Error()` convention — `"img request failed (%d): %s"`).

### 制約

- Do not hand-edit `cli/internal/img/openapigen/openapi.gen.go` — it's generated by `go generate
  ./...`, exactly like `cli/internal/connpass/openapigen/`.
- Do not add a `--json`/`--from-file` raw-body-passthrough flag pattern here (connpass's
  `addJSONBodyFlags` exists for its arbitrary event-field updates) — img's four operations have
  fixed, small argument shapes; keep the flags explicit and typed instead of accepting raw JSON.
